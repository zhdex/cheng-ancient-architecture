# 承古建筑官网 v4.0

> 湖南承古建筑有限公司 — 26年中式四合院全流程服务商

## 🌟 特性亮点

### 设计系统
- ✅ CSS Custom Properties (设计令牌)
- ✅ 中式美学配色 (墨色+暖金+朱红)
- ✅ Apple式电影感节奏 (明暗交替)
- ✅ Stripe式精致阴影系统
- ✅ 响应式设计 (桌面/平板/手机)
- ✅ 无障碍访问 (ARIA标签、键盘导航)

### 高级动效
- ✅ GSAP 3.12 + ScrollTrigger
- ✅ Three.js 3D粒子背景 (金色萤火虫)
- ✅ Hero入场动画 (逐行文字展开)
- ✅ 滚动触发淡入动画
- ✅ 视差滚动效果
- ✅ 数字计数器动画
- ✅ 按钮涟漪效果
- ✅ 案例卡片金色边框悬停

### GEO优化 (Generative Engine Optimization)
- ✅ Schema.org 结构化数据 (LocalBusiness + FAQPage)
- ✅ 语义化HTML5标签 (article, section, nav, main)
- ✅ Open Graph + Twitter Cards
- ✅ robots.txt 允许AI爬虫访问
- ✅ llms.txt 为LLM提供网站摘要
- ✅ sitemap.xml 帮助搜索引擎理解结构
- ✅ 表单无障碍 (label + for 属性)

### 性能优化
- ✅ CSS/JS 分离 (无内联样式)
- ✅ 图片懒加载 (loading="lazy")
- ✅ GSAP/Three.js CDN + defer加载
- ✅ Hero图片 eager加载
- ✅ Safari兼容 (-webkit-backdrop-filter)

```
cheng-ancient-architecture/

├── js/
│   ├── main.js         # GSAP动效脚本
│   └── three-bg.js     # Three.js 3D背景
├── images/
│   ├── hero-bg.jpg     # Hero背景图
│   ├── about-bg.jpg    # 关于我们背景
│   ├── case1.jpg       # 案例1
│   ├── case2.jpg       # 案例2

├── llms.txt            # LLM网站摘要
├── package.json        # 项目配置
└── .gitignore          # Git忽略文件
```

## 🚀 快速开始

### 直接打开
直接在浏览器中打开 `index.html` 即可预览。

### 本地开发
```bash
npm install
npm run dev
```

## 🎨 设计系统

### 配色方案
- **墨色**: #0c0a09 (主色调)
- **金色**: #b08d57 (强调色)
- **朱红**: #c23b22 (点缀色)
- **纸色**: #faf9f6 (背景色)

### 字体
- **标题**: Noto Serif SC (宋体风格)
- **正文**: Noto Sans SC (黑体风格)

## 📱 响应式断点

- **桌面**: > 1024px
- **平板**: 768px - 1024px
- **手机**: < 768px
- **小手机**: < 480px
